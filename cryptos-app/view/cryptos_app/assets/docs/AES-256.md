# AES-256 Encryption and Decryption

This is a Python implementation of **AES-256** (Advanced Encryption Standard using a 256-bit key). It supports encryption and decryption of strings using **block-wise processing**, **PKCS#7 padding**, and **Base64 output encoding**.

---

## Overview

AES-256 is a symmetric key encryption algorithm that operates on 128-bit (16-byte) data blocks using a 256-bit (32-byte) encryption key. It performs **14 rounds** of transformation to ensure strong encryption.

---

## Features

- 🔐 **AES-256 with 32-byte key support**
- 🔄 **Encrypt/Decrypt** using `encode` and `decode` operations
- 📦 **Block-based encryption** with PKCS#7 padding
- 📤 **Base64-encoded ciphertext** for safe output
- ⚠️ **Auto key padding/truncation** with warnings
- 🧪 **Full AES round logic including S-Box, ShiftRows, MixColumns**

---

## Encryption Process

### Steps:

1. **Key Handling**
   - Pads or truncates the key to exactly 32 bytes.

2. **Plaintext Preparation**
   - Converts input string to UTF-8 encoded bytes.
   - Applies PKCS#7 padding to make the plaintext a multiple of 16 bytes.

3. **Block Encryption**
   - Splits the plaintext into 16-byte blocks.
   - Encrypts each block using AES-256 transformations.

4. **Encoding Output**
   - Joins encrypted blocks and encodes the result in Base64.

---

## Decryption Process

### Steps:

1. **Key Handling**
   - Pads or truncates the key to 32 bytes.

2. **Base64 Decoding**
   - Decodes the Base64-encoded ciphertext into raw bytes.

3. **Block Decryption**
   - Splits ciphertext into 16-byte blocks.
   - Decrypts each block using AES-256 inverse rounds.

4. **Unpadding**
   - Removes PKCS#7 padding to retrieve the original plaintext.

---

## Key Functions

### AES Core Operations

- `sub_bytes()` and `inv_sub_bytes()`: Byte substitution using S-box.
- `shift_rows()` and `inv_shift_rows()`: Row rotations for diffusion.
- `mix_columns()` and `inv_mix_columns()`: Column transformations using Galois Field math.
- `add_round_key()`: XORs state with the round key.

### Key Expansion

- `expand_key()`: Generates the full key schedule using rotation, S-box, and Rcon.
- AES-256 uses **14 rounds** + 1 initial round key = **240 bytes** of expanded key.

---

## Padding Strategy

- **PKCS#7** is used to ensure data fits block sizes.
- `pad()` appends `N` bytes of value `N` (e.g., 3 bytes of `0x03`).
- `unpad()` removes valid padding after decryption.
