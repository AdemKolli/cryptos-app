# AES-128 Encryption and Decryption Implementation

This implementation of AES-128 encryption and decryption provides a compact yet powerful solution for securely encrypting and decrypting strings. **AES (Advanced Encryption Standard)** is a symmetric block cipher widely used in modern cryptography for securing sensitive data.

---

## How It Works

AES-128 operates on 128-bit (16-byte) blocks of data using a key of 128 bits. The encryption and decryption involve multiple rounds of transformations, including substitution, permutation, and mixing of data.

This implementation adheres to AES-128 standards and is implemented in Python.

---

### Key Features

- **Padding support**: Automatically pads input data to meet the 16-byte block size.
- **Base64 encoding**: Encodes encrypted data in Base64 for safe transmission.
- **AES rounds**: Uses 10 rounds for AES-128 encryption and decryption.
- **Input validation**: Ensures input integrity and key length constraints.

---

## Encryption

### Process

1. **Key Preparation**
   - Truncates or pads the key to 16 bytes as needed.

2. **Plaintext Preparation**
   - Converts the plaintext to UTF-8.
   - Applies PKCS#7 padding to align the input to 16-byte blocks.

3. **Block-by-Block Encryption**
   - Splits plaintext into 16-byte blocks.
   - Encrypts each block using AES algorithm.
   - Combines the encrypted blocks into the final ciphertext.

4. **Base64 Encoding**
   - Encodes the ciphertext in Base64 format for safe handling.

---

## Decryption

### Process

1. **Key Preparation**
   - Adjusts the key to exactly 16 bytes.

2. **Base64 Decoding**
   - Decodes the Base64-encoded ciphertext to binary data.

3. **Block-by-Block Decryption**
   - Splits the ciphertext into 16-byte blocks.
   - Decrypts each block.
   - Combines the decrypted blocks into the original plaintext.

4. **Padding Removal**
   - Removes PKCS#7 padding from the plaintext.

---

## Core Functions

### Key Expansion

- `expand_key()` – Generates the key schedule for AES rounds.
  - `rotate()` – Rotates a word's bytes.
  - `core()` – Applies S-Box substitution and Rcon.

### Block Operations

- `aes_encrypt_block()` – Encrypts one 16-byte block.
- `aes_decrypt_block()` – Decrypts one 16-byte block.
- `add_round_key()` – XORs state with the round key.
- `sub_bytes()` – Applies S-Box substitution.
- `shift_rows()` – Performs row-wise circular shift.
- `mix_columns()` – Mixes columns via Galois field operations.

### Padding

- `pad()` – Applies PKCS#7 padding.
- `unpad()` – Removes padding.

### Base64 Handling

- Ensures encryption outputs are Base64-encoded.
- Decodes Base64 before decryption.

### Error Handling

- Validates key length and input formats.
- Provides descriptive error messages.

---

## Notes and Recommendations

- 🔐 **Key Length**: Always use a 16-byte key.
- ⚠️ **Padding Warnings**: Warnings issued for auto-truncation or padding of keys.
- ⚠️ **Base64 Errors**: Ensure the ciphertext is a valid Base64 string.
