# SHA-256 Algorithm

**SHA-256** (Secure *Hash* Algorithm 256-bit) is a cryptographic hash function that produces a fixed-size 256-bit (32-byte) hash. It is widely used in data integrity verification and cryptographic applications due to its resistance to collisions and pre-image attacks.

---

## How It Works

### 1. Preprocessing

- Converts the input string to binary by transforming each character into its ASCII value and then into an 8-bit binary representation.
- Groups the binary sequence into 32-bit chunks for further processing.
- Padding is added to ensure the final message length is a multiple of 512 bits:
  - A single `'1'` bit is appended
  - Zero bits are added until the length is 64 bits short of a multiple of 512
  - Finally, the original length of the message (in bits) is appended as a 64-bit binary number
- Splits the final binary stream into blocks of 512 bits (16 chunks of 32 bits)

---

### 2. Initialization

- Uses eight fixed 32-bit values derived from the square roots of the first 8 prime numbers. These values are stored as variables `a` through `h` and serve as the initial hash values.
- Creates a list of 64 constants using the fractional parts of the cube roots of the first 64 prime numbers, which are used in the compression function.

---

### 3. Message Schedule (W values)

For each 512-bit block:

- The first 16 values are directly taken from the block
- The remaining 48 values are generated using two auxiliary functions `sigma0()` and `sigma1()` based on bitwise operations (rotations and shifts)

---

### 4. Compression Function

For each of the 64 rounds:

- Two intermediate values `t1` and `t2` are calculated using:
  - Bitwise functions: `σ0`, `σ1`, `ch` (choose), and `maj` (majority)
  - The current working variables `a` through `h`
  - The round constant and corresponding word from the message schedule
- Updates the working variables in each round by propagating the values through rotations
- After processing each block, the working variables are added to the current hash state

---

### 5. Final Hash Construction

- After processing all blocks, the final hash is obtained by concatenating the values of the updated variables `a` through `h`
- The result is returned as a 64-character hexadecimal string, representing the 256-bit SHA-256 hash
